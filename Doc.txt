Build a LinkedIn AI Social Media Agent as a single-page React application on python that lets users generate professional LinkedIn posts by calling the Anthropic Claude API directly from the frontend.

---

## App Overview

The app is called "LinkedAI" — a sleek, minimal tool for crafting high-quality LinkedIn content. It has two main views: a Post Generator and a Preview Panel.

---

## Features to Build

### 1. Post Generator Form
Build a form with the following inputs:
- **Topic / Idea** (textarea): What the post should be about
- **Tone selector** (dropdown or pill buttons): Options — Professional, Inspirational, Storytelling, Thought Leadership, Casual, Humorous
- **Post format** (dropdown): Options — Short hook (< 150 words), Listicle (numbered tips), Personal story, Opinion/Hot take, Achievement announcement
- **Target audience** (text input): e.g., "CTOs", "Job seekers", "Startup founders"
- **Include CTA** (toggle): If on, append a clear call-to-action
- **Add emojis** (toggle): If on, sprinkle relevant emojis
- **Hashtag count** (slider, 0–10): How many hashtags to append
- **Generate Post** button

### 2. Claude API Integration
When the user clicks "Generate Post", call the Anthropic Claude API:

```js
const response = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": apiKey,
    "anthropic-version": "2023-06-01"
  },
  body: JSON.stringify({
    model: "claude-sonnet-4-20250514",
    max_tokens: 1000,
    system: `You are an expert LinkedIn content creator. You write posts that feel authentic, 
get high engagement, and match the requested tone perfectly. Always output ONLY the post text — 
no preamble, no explanation, no quotes around the post.`,
    messages: [{
      role: "user",
      content: buildPrompt(formValues)
    }]
  })
});
```

Build a `buildPrompt(formValues)` function that assembles a detailed instruction from the form fields, e.g.:
"Write a [tone] LinkedIn post in [format] format about: [topic]. Target audience: [audience]. [If CTA enabled: End with a strong call-to-action.] [If emojis enabled: Use relevant emojis naturally.] Include [N] hashtags at the end."

### 3. API Key Input
- Show a small settings panel (collapsible or modal) where the user enters their Anthropic API key
- Store it in component state only (never localStorage)
- Show a masked input (password type) with a toggle-visibility button
- Display a warning: "Your key is used client-side. For production, proxy through a backend."

### 4. Post Preview Panel
After generation:
- Display the generated post in a LinkedIn-style card mockup (white card, profile avatar placeholder, name placeholder, "LinkedIn • Just now")
- Show character count (LinkedIn limit: 3000 chars) with a color indicator (green/amber/red)
- Show a word count
- Add a **Copy to Clipboard** button
- Add a **Regenerate** button (calls API again with same inputs)
- Add an **Edit** button to make the output editable in-place

### 5. Post History (in-memory)
- Keep a sidebar or bottom drawer with the last 5 generated posts
- Each history item shows a truncated preview (first 60 chars) and the tone/format used
- Clicking a history item loads it back into the preview

### 6. Prompt Templates (optional enhancement)
Offer 4–5 preset "starter templates" that auto-fill the form:
- "Share a career lesson"
- "Announce a product launch"
- "Give an industry opinion"
- "Share a team win"
- "Offer a practical tip"

---

## UI / Design Requirements

- Clean, professional aesthetic — inspired by LinkedIn's own blue palette but more minimal
- Responsive layout: two-column (form left, preview right) on desktop; stacked on mobile
- Loading state: animated skeleton or spinner on the preview card while API call is in flight
- Error handling: show clear error messages if API key is missing, invalid, or rate-limited
- Use Tailwind CSS for styling (or plain CSS modules — your choice)
- No external UI libraries required; keep it lightweight

## How to Run the App

### Prerequisites
- Python 3.10+
- Node.js 18+
- A `.env` file in `linkedin-ai-agent/backend/` with your OpenAI API key
- A `.env.local` file in `linkedin-ai-agent/frontend/` with your Supabase credentials

### 1. Set up environment files

Backend — create `linkedin-ai-agent/backend/.env`:
  OPENAI_API_KEY=sk-...

Frontend — create `linkedin-ai-agent/frontend/.env.local`:
  NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
  NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

### 2. Start the backend (FastAPI)

  cd linkedin-ai-agent/backend
  source ../../../venv/bin/activate
  uvicorn main:app --reload --port 8000

Backend runs at: http://localhost:8000

### 3. Start the frontend (Next.js)

Open a second terminal tab:

  cd linkedin-ai-agent/frontend
  npm install        # only needed the first time
  npm run dev

Frontend runs at: http://localhost:3000

### 4. Open the app

Go to http://localhost:3000 in your browser.
You will be redirected to /login. Sign up or log in to use the app.

Both the backend and frontend must be running at the same time.
