01 — Overview

Executive Summary

The LinkedIn AI Content Agent is a human-in-the-loop SaaS product that automates the full lifecycle of professional content on LinkedIn — from ideation to publishing. The agent uses large language models to draft posts, applies configurable review criteria to self-evaluate content quality, presents drafts to a human approver, and schedules or publishes upon approval.

The product is designed for professionals, founders, and marketing teams who want consistent LinkedIn presence without sacrificing authenticity or brand voice. Human approval is a first-class feature — not an afterthought — ensuring the agent never publishes anything without explicit sign-off.

Core Principle

The agent proposes; humans decide. Every published post carries a human signature, not just an AI fingerprint.

02 — Context

Problem Statement

LinkedIn is the dominant B2B professional network, yet most users post inconsistently or not at all. The friction points are well-documented: blank-page paralysis, time scarcity, uncertainty about tone, and lack of a structured content workflow.

Existing AI writing tools generate text but lack the opinionated workflow needed for LinkedIn: they don't understand professional context, can't self-review against brand guidelines, and have no scheduling or approval layer. This results in either over-reliance on generic AI output (risking brand damage) or continued under-use of the platform.

Key Insight

The gap is not writing ability — LLMs can write competent posts. The gap is workflow: ideation → draft → review → approve → schedule → publish, all in one cohesive, trustworthy loop.

03 — Scope

Goals & Non-Goals

Goals

G-01
Autonomous Content Generation

Generate high-quality LinkedIn drafts from topics, URLs, notes, or context documents with minimal user input.

G-02
AI-Powered Self-Review

The agent critiques its own drafts against configurable brand voice, tone, and engagement criteria before surfacing them.

G-03
Human Approval Gate

Every post requires explicit human approval — approve, edit & approve, or reject — before it can be scheduled or published.

G-04
Smart Scheduling

Recommend and execute optimal posting times based on audience analytics, then publish via LinkedIn API.

G-05
Brand Voice Fidelity

Learn and maintain the user's personal or company voice across all generated content.

G-06
Analytics & Learning

Track post performance and feed insights back into future generation to continuously improve output quality.

Non-Goals (v1)

The following are explicitly out of scope for version 1: multi-platform support (Twitter/X, Instagram), comment moderation automation, image/video generation, team collaboration features, and LinkedIn DM management.

Sub-Agent Responsibilities

AI
Ideation Agent

Monitors news feeds, user-provided topics, past post performance, and industry trends. Produces a ranked list of content angles daily/weekly.

AI
Writer Agent

Takes an approved angle and generates 1–3 draft variants in the user's defined voice. Supports post types: thought leadership, how-to, story, list, hot take.

AI
Reviewer Agent

Scores each draft on engagement potential, brand voice fit, clarity, and LinkedIn algorithm alignment. Revises or rejects low-scoring drafts before surfacing to human.

Core
Scheduler Agent

Calculates optimal posting windows using audience timezone data and historical engagement patterns. Manages the posting queue and respects frequency limits.

06 — Features

Core Features

Content Generation

AI
Multi-format Drafts

Generate text posts, carousels (slide outlines), polls, and article intros. Each format has format-specific prompting logic.

AI
Source Ingestion

Paste a URL, upload a PDF, or type a note — the agent extracts key insights and builds post drafts around them.

AI
Voice Profiling

Analyze the user's past LinkedIn posts to build a reusable voice profile: vocabulary, tone, sentence length, emoji usage, CTA style.

UX
Variant Generation

Every draft surfaces 2–3 variants (e.g., punchy vs. narrative vs. data-led). Humans pick the starting point.

Review & Quality Control

AI
Auto-Critique

The Reviewer Agent scores each draft on 5 dimensions: hook strength, clarity, value delivery, brand alignment, CTA effectiveness.

AI
Revision Loop

Drafts scoring below threshold are automatically revised up to 2 times before being surfaced or discarded.

Core
Brand Guidelines

Upload a brand guide or fill a structured form. Reviewer Agent enforces: banned words, required disclaimers, tone constraints.

Safety
Compliance Filter

Flags potentially sensitive content (claims, financials, legal statements) for mandatory human review before approval is unlocked.

Human Approval Interface

UX
Approval Inbox

Clean, mobile-first queue of posts awaiting review. Each card shows the draft, AI score breakdown, and suggested schedule time.

UX
Inline Editor

Edit the draft directly in the approval view. Changes trigger a live re-score. Approve with or without edits.

UX
Reject with Reason

Rejecting a post prompts a reason (optional). Reasons are fed back to the Writer Agent to improve future generations.

Integration
Notification Channels

Approval requests delivered via in-app, email, or Slack. One-click approve for low-risk, trusted-content scenarios.

Scheduling & Publishing

Core
Content Calendar

Visual calendar view of approved and scheduled posts. Drag-and-drop rescheduling. Frequency guardrails to prevent over-posting.

AI
Optimal Time Engine

Recommends top 3 posting windows per week based on audience timezone distribution and historical engagement data.

Integration
LinkedIn API Publishing

Publishes via official LinkedIn API. Supports text posts, images, article links, and polls. Handles API rate limits gracefully.

Core
Queue Management

Pause, resume, or reschedule the entire queue. Emergency "pull" feature to retract a post immediately after publishing.

08 — Workflow

Human Approval Flow

The approval workflow is the trust layer of the product. It is designed to be fast for routine content and rigorous for sensitive content.

Design Principle

No post ever publishes without a human touching an approval action. Even auto-schedule requires prior approval of the draft and the time window.

Standard Flow

Step 1
Draft Arrives in Inbox

The Reviewer Agent surfaces a scored draft. User receives a push/email/Slack notification with a preview snippet.

Step 2
Review the Draft

Open the full draft with AI score breakdown: hook (8/10), voice match (9/10), clarity (7/10), CTA (8/10). See suggested schedule time.

Step 3a
Approve As-Is

Tap Approve. Post moves to scheduled queue at AI-recommended time (or user-selected override). No further action required.

Step 3b
Edit & Approve

Make inline edits. Live re-score reflects changes. Tap Approve Edited Version. Post enters queue with edited content.

Step 3c
Request Revision

Leave a note ("make it shorter", "add a data point"). Agent revises and resubmits within minutes. Returns to Step 2.

Step 3d
Reject

Reject with optional reason tag. Draft is archived. Rejection reason is logged to improve future generation quality.

Escalation Rules

The following trigger a mandatory senior-approver review and disable one-tap approval: posts containing financial claims, legal statements, product pricing, competitor mentions, or content flagged by the compliance filter. Escalation is configurable per team.

Key Technical Decisions

State Management

Each post draft carries a full state machine: DRAFT → REVIEWING → PENDING_APPROVAL → APPROVED → SCHEDULED → PUBLISHED (or REJECTED / RETRACTED at any stage). All state transitions are event-sourced for auditability.

Voice Profile Storage

Voice profiles are stored as vector embeddings + structured JSON (tone flags, vocabulary lists). Updated incrementally each time the user approves/rejects a draft with feedback.

LinkedIn API Constraint

LinkedIn's API imposes rate limits and approval requirements. The publisher must implement exponential backoff, handle 429s gracefully, and surface API errors clearly in the UI without data loss.

12 — Risk Management

Risks & Mitigations

Risk Severity Likelihood Mitigation
LinkedIn API deprecation or policy change blocks publishing High Medium Monitor LinkedIn Developer changelog. Abstract publisher layer. Manual publish export as fallback.
AI generates factually incorrect or brand-damaging content High Medium Human approval gate is the primary control. Compliance filter adds secondary layer. User training and clear disclaimers.
Voice profile doesn't reflect user's actual style Medium High Iterative feedback loop from approvals and rejections. Allow manual profile editing. Offer "re-learn from scratch" reset.
Approval fatigue leads to rubber-stamp approvals Medium Medium Minimize approval friction. Improve draft quality to reduce review burden. Consider trust-score-gated auto-approve for recurring patterns.
LLM API costs become unsustainable at scale Medium Low Cache voice profiles. Limit revision loops. Offer tiered plans. Evaluate smaller fine-tuned models for v2.
Users lose trust if a post publishes without their awareness High Low Hard constraint: no publish without explicit approval action logged. Full audit trail. Immediate retract feature.
